Reproduire les résultats

git clone https://github.com/astrak69/Modele-de-prediction-de-la-fluctuation-des-cours-des-metaux-rares..git
cd Modele-de-prediction-de-la-fluctuation-des-cours-des-metaux-rares.
pip install -r requirements.txt

python run_pipeline.py --open        # chaîne complète, ouvre les livrables
python run_pipeline.py --skip-download   # recalcul sur l'historique local
Périmètre — 1 321 séances quotidiennes du 24/08/2021 au 24/08/2026 · 13 règles de signal × 5 horizons = 65 combinaisons testées, 11 retenues.
Les résultats reposent sur une simulation historique et ne préjugent pas des performances futures. Document à usage interne, ne constituant pas une recommandation d'investissement.
